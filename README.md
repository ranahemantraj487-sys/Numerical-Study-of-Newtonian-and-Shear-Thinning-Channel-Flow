# Numerical-Study-of-Newtonian-and-Shear-Thinning-Channel-Flow
Developed a finite-difference model of pressure-driven channel flow using a power-law constitutive relation to compare Newtonian and shear-thinning fluids.  Analysed velocity profiles, wall shear stress and flow behaviour across different rheological parameters.  Verified the Newtonian case against the analytical Poiseuille solution .
